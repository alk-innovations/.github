# ALK Innovations

The entrepreneurial holding and laboratory of Quentin Georget, based in France.
Each product is built and run as its own autonomous company project.

## Products

- **[Trupeo](https://www.trupeo.com)**: the shared mailbox for small teams and associations.
  Gmail, Outlook and IMAP, one inbox the whole team works from.
- **[Crenomi](https://www.crenomi.com)**: every calendar in sync, one availability to book time with anyone.
- **[Zibou](https://www.zibou.app)**: short, playful mini-games that help children practise school topics.
